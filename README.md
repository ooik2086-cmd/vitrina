# VITRINA AI — алғашқы код

Күйі (16.10.2026): репозиторий әлі жоқ, файлдар жобаның ортақ папкасында.

## Не бар

| Папка | Не | Деңгейі |
| --- | --- | --- |
| `backend/vitrina_core/orders.py` | Тапсырыс күйлерінің машинасы: 14 күй, кім қай өтуді жасай алады, трек-нөмір, авто-аяқтау мерзімі | Жұмыс істейді, тестті |
| `backend/vitrina_core/money.py` | Ақша тиынмен (float жоқ), комиссия (basis point, нұсқаланған), өзгермейтін ledger, бөліп есеп айырысу | Жұмыс істейді, тестті |
| `backend/vitrina_core/webhooks.py` | Төлем webhook: HMAC қолтаңба, уақыт белгісі, сома тексерісі, қайталанған оқиға | Жұмыс істейді; нақты провайдердің схемасына әлі бейімделмеген |
| `backend/vitrina_core/catalog.py` | Баға сегменттері каталог деректерінен, жағдай мен түпнұсқалық бөлек, бренд синонимдері мен транслитерация | Жұмыс істейді, тестті |
| `backend/vitrina_api/` | HTTP API (FastAPI) + дерекқор (SQLAlchemy, 15 кесте): телефон+код арқылы кіру, профиль, сатушы режимі, тауар жариялау, іздеу (кирилл/латын), таңдаулылар, тапсырыс, төлем мен жеткізу webhook-тары, дау шешу, аудит | Жұмыс істейді, 18 API тесті; SMS пен төлем — sandbox |
| `prototype/vitrina-360.html` | Тауар бетінің прототипі: 360° кадр тізбегі, 3 стиль, өлшем, тапсырыс парағы | Прототип; аяқкиім синтетикалық 3D модель |

Әлі жоқ: Flutter қосымшасы, чат пен пікірлер, файл жүктеу (фото URL ретінде келеді), миграциялар (Alembic), нақты SMS, төлем және жеткізу провайдерлері, суретпен іздеу, фон алу.

## Тесттерді іске қосу

Python 3.11+ керек.

```
cd backend
python3 -m pip install -r requirements.txt
python3 -m unittest -v
```

Күтілетін нәтиже: `Ran 45 tests ... OK` (27 домен тесті + 18 API тесті).

## Серверді іске қосу

```
cd backend
python3 -m uvicorn vitrina_api.app:create_app --factory --reload
```

API құжаты: http://127.0.0.1:8000/docs. Әдепкі дерекқор — `vitrina-dev.db` (SQLite); PostgreSQL үшін `VITRINA_DATABASE_URL` орнатыңыз. Әзірлеу режимінде SMS орнына код жауапта `dev_code` болып қайтады; production-да `VITRINA_DEBUG_OTP=0` және барлық `VITRINA_*_SECRET` мәндерін орнату міндетті.
