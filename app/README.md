# VITRINA — Flutter қосымшасы

Android бірінші. Экрандар: каталог және іздеу (атау, бренд, ұлтарақ ұзындығы см), тауар беті 360° көрсеткішімен, телефон+код арқылы кіру, таңдаулылар, тапсырыстар (сатып алушы мен сатушы), профиль және сатушы режимі.

## Іске қосу

Алдымен серверді түбірдегі `README.md` бойынша іске қосыңыз, содан кейін:

```
flutter pub get
flutter run                      # Android эмуляторы: сервер 10.0.2.2:8000 мекенжайында
flutter run --dart-define=API_BASE=http://192.168.1.10:8000/api/v1   # нақты телефон, бір Wi-Fi желісінде
```

Debug нұсқасы жергілікті серверге HTTP арқылы қосыла алады; release нұсқасы тек HTTPS.

## 360° қалай жұмыс істейді

Сатушы аяқкиімді айналдыра түсірген нақты фотолар (`angle: "frame"`, кемінде 8 кадр) ретімен көрсетіледі. Саусақпен көлденең сүйрегенде кадр ауысады. Кадрлар арасында ештеңе генерацияланбайды, сондықтан тауардың пішіні, түсі мен ақауы өзгермейді. Кадр аз болса, кәдімгі фото галерея шығады.

## Google Play-ге шығару

Дүкенге тек серверге қосылатын, жүктеу кілтімен (upload key) қол қойылған App Bundle (`.aab`) жіберіледі. Демо APK оған жарамайды.

1. Кілтті бір рет жасаңыз (Java-сы бар кез келген компьютерде):
   ```
   keytool -genkeypair -v -keystore vitrina-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   base64 -w0 vitrina-upload.jks > vitrina-upload.b64
   ```
   Мұны репозиторий қалтасынан тыс жерде жасаңыз. `.jks` файлы мен құпия сөздерді екі жерде сақтаңыз, ал сертификаттың SHA-256 саусақ ізін (`keytool -list -v -keystore vitrina-upload.jks`) GitHub-тағы `VITRINA_UPLOAD_CERT_SHA256` айнымалысына (Variables) жазыңыз: сонда workflow басқа кілтпен қол қойылған нұсқаны шығармайды. Play Console-да Play App Signing қосулы болса, жоғалған жүктеу кілтін Google арқылы ауыстыруға болады.
2. GitHub → Settings → Secrets and variables → Actions бөліміне төрт құпия қосыңыз:
   - `VITRINA_UPLOAD_KEYSTORE_BASE64`: `vitrina-upload.b64` ішіндегі мәтін;
   - `VITRINA_UPLOAD_STORE_PASSWORD`;
   - `VITRINA_UPLOAD_KEY_ALIAS`: `upload`;
   - `VITRINA_UPLOAD_KEY_PASSWORD`.
3. Actions → **Store release** → Run workflow, сервер мекенжайы: `https://ДОМЕН/api/v1`. Дайын `.aab` сол іске қосудың Artifacts бөлімінде болады (30 күн). Нұсқа нөмірі іске қосу нөмірінен алынады (нөмір × 10 + қайталау), сондықтан әр жолы өседі. Google Play-ге тек осы workflow жинаған нұсқаларды жүктеңіз: компьютерде жиналған нұсқаның нөмірі pubspec-тегі `+1` болады.
4. `.aab`-ты Play Console-ға жүктеңіз. Деректер қауіпсіздігі (Data safety) бөлімінде құпиялылық беті `https://ДОМЕН/privacy`, ал аккаунтты өшіру беті `https://ДОМЕН/delete-account`.

Компьютерде жинау үшін `android/key.properties` файлы жеткілікті (`storeFile` толық жолмен не `android/app` қалтасына қатысты, `storePassword`, `keyAlias`, `keyPassword`; ол git-ке түспейді). Кілтпен жиналған нұсқа `--dart-define=API_BASE=https://...` берілмесе, жиналмайды: әйтпесе әр телефон «байланыс жоқ» деп көрсететін еді. Кілт болмаса, release нұсқасы debug кілтімен қол қойылады. Бұл демо APK үшін жарайды, бірақ Google Play оны қабылдамайды.

`applicationId` (`kz.vitrina.vitrina`) бірінші жүктеуден кейін өзгермейді.

## Әлі жоқ

- Онлайн төлем: лицензиясы бар төлем серіктесі таңдалмаған. Сервер `VITRINA_PAYMENTS=off` режимінде тапсырыс пен баға ұсынысын қабылдамайды, ал тауар бетіндегі батырма «Сатушыға жазу» болып, чатты ашады.
- Push-хабарламалар (FCM).
